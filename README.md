# پروژه نهایی اپلیکیشن احراز هویت اندروید (Final Project - Android Login App)

این پروژه یک برنامه اندرویدی مبتنی بر **Java** در محیط **Android Studio** است که شامل صفحه لاگین با اعتبارسنجی و انتقال داده به اکتیویتی دوم است.

## 📱 ویژگی‌های برنامه
- **صفحه ورود (MainActivity):**
  - فیلد دریافت نام کاربری
  - فیلد دریافت رمز عبور (با قابلیت پنهان‌سازی رمز عبور)
  - بررسی اطلاعات ورودی
  - نمایش پیام خطا (`Toast`) در صورت نادرست بودن اطلاعات: **«نام یا رمز عبور اشتباه است»**
- **صفحه دوم (SecondActivity):**
  - دریافت نام کاربری از طریق `Intent`
  - نمایش عبارت **`نام کاربری: mikibnsd`** در بالاترین قسمت اکتیویتی
  - پیام خوش‌آمدگویی

## 🚀 نحوه اجرا در Android Studio
1. پروژه را با گیت کلون کرده یا دانلود کنید:
   ```bash
   git clone https://github.com/chelsea752/final_project.git
   ```
2. نرم‌افزار **Android Studio** را باز کرده و گزینه **Open** را انتخاب نمایید.
3. پوشه پروژه را انتخاب کرده و منتظر اتمام عملیات Gradle Sync بمانید.
4. روی دکمه **Run (Shift + F10)** کلیک کنید تا برنامه روی امولاتور یا دستگاه واقعی اجرا شود.
